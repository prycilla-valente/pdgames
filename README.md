🎮 PD Games

Bem-vindo ao PD Games, um site desenvolvido para uma loja de jogos clássicos, com foco em nostalgia, diversão e experiências inesquecíveis para os amantes de videogames.

📖 Sobre o projeto

A PD Games é uma loja virtual de jogos e consoles que apresenta produtos, informações sobre a empresa e galerias inspiradas em grandes clássicos dos videogames.

O projeto foi desenvolvido utilizando HTML5 e CSS3, com uma interface simples, organizada e responsiva.

🌐 Páginas do projeto
🏠 Página Inicial

Apresenta o banner principal da PD Games e uma introdução sobre a loja.

O site possui um sistema de alternância entre modo claro e modo escuro, permitindo que o usuário altere o tema da página.

▶️ Como executar
Baixe ou clone o projeto.
Abra a pasta no Visual Studio Code.
Abra o arquivo index.html.
Utilize o Live Server para executar o projeto.
Acesse a página pelo navegador.
🎯 Objetivo do projeto

O objetivo da PD Games é criar uma experiência visual agradável e nostálgica para apresentar uma loja de jogos clássicos.

O projeto também tem como finalidade praticar conceitos de:

Estruturação de páginas com HTML;
Estilização com CSS;
Navegação entre páginas;
Organização de arquivos;
Criação de galerias;
Implementação de tema claro e escuro;
Desenvolvimento de interfaces para a web.
