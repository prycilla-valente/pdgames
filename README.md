# 🎮 PD Games

Bem-vindo ao **PD Games**, um site desenvolvido para uma loja de jogos clássicos, com foco em nostalgia, diversão e experiências inesquecíveis para os amantes de videogames.

## 📖 Sobre o projeto

A **PD Games** é uma loja virtual de jogos e consoles que apresenta produtos, informações sobre a empresa e galerias inspiradas em grandes clássicos dos videogames.

O projeto foi desenvolvido utilizando **HTML5 e CSS3**, com uma interface simples, organizada e responsiva.

## 🎯 Objetivo

O objetivo do projeto foi colocar em prática os conhecimentos adquiridos durante o curso de **HTML5 e CSS3**, desenvolvendo um site completo com diferentes páginas e recursos de estilização.

## 🕹️ Páginas do projeto

O site possui as seguintes páginas:

- 🏠 **Início** — apresentação da PD Games;
- 🎮 **Produtos** — vitrine com jogos clássicos;
- ℹ️ **Sobre** — informações sobre a empresa;
- 🖼️ **Galeria** — galeria de imagens de jogos;
- 📩 **Contato** — formulário de contato.

## 🎮 Jogos apresentados

Entre os jogos apresentados no projeto estão:

- Super Mario World
- Donkey Kong
- Street Fighter
- F-Zero

## ✨ Funcionalidades

- Navegação entre páginas;
- Vitrine de produtos;
- Galeria de imagens;
- Formulário de contato;
- Botão para voltar;
- Tema claro e escuro;
- Layout responsivo;
- Efeitos e estilizações utilizando CSS.

## 🌙 Tema claro e escuro

Como atividade extra, foi implementado um sistema de **tema claro e escuro utilizando apenas HTML e CSS**, sem JavaScript.

O tema escuro foi utilizado como padrão para combinar com a identidade visual da PD Games.

## 🖼️ Galeria de imagens

Também foi desenvolvida uma **galeria de imagens** como atividade extra.

A galeria foi criada utilizando HTML e CSS, mantendo uma estrutura organizada e adaptável a diferentes tamanhos de tela.

## 📩 Formulário de contato

Foi desenvolvido um formulário de contato como atividade extra, contendo campos para preenchimento das informações do usuário e envio de mensagens.
